# CLUSTER Brand Assets v2.0

This package separates the logo, variants, patterns, icons, palette, and application references.

## Official logo source
`07_Source_References/original_logo_source.png` is the approved logo-only raster reference supplied in this conversation. The SVGs in `01_Logo` are traced from that exact emblem artwork rather than a newly invented symbol.

## Logo variants
- Primary: black emblem + acid-lime three-spark detail.
- Monochrome black: single-ink version for light backgrounds and one-colour print.
- Reversed white: single-white version for dark backgrounds.
- White + lime sparks: alternate reversed treatment.
- Teal gradient: optional experimental alternate; not the default palette.
- Symbol-only exports and horizontal wordmark lockups are provided separately.

## Core palette
- Ink: #080808
- Off-white: #F8F7F3
- Graphite: #3A3A3A
- Acid lime: #C6FF4D

Optional teal alternative:
- Deep teal: #087F82
- Bright teal: #22D3C5

Use lime as the core accent in the supplied lime reference identity. Use teal only when intentionally selecting the alternate teal direction. Avoid mixing both accents in one application.

## Logo rules
- Do not redraw, skew, stretch, rotate, or change the interlocking emblem geometry.
- Keep the three spark strokes for normal-size use. Drop the sparks below approximately 24 px or where the mark becomes unclear.
- Do not use gradient fills for text, links, or single-colour printing.
- Use monochrome black on light backgrounds and reversed white on dark backgrounds.
- SVG files are editable vector paths. Wordmark text in lockup SVGs remains live text; convert it to outlines in a design tool before final print production if exact font portability is required.

## Brand assets
- `02_Brand_Applications`: supplied board and banner reference images.
- `03_Patterns`: editable dot field, pixel cluster, connection path.
- `04_Icons`: six consistent editable SVG icons.
- `05_Colour_Palette`: colour swatches and usage notes.
